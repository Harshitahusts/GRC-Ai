# Sample files for data discovery

Synthetic data only. Every name, number and address here is made up; the Aadhaar and
PAN values are generated so their format and checksum are valid, and belong to no one.

- `customers_sample.csv`: an e-commerce customer export (names, contacts, Aadhaar, PAN,
  UPI IDs, addresses, a few customers under 18, free-text support notes).
- `clinic_patients_sample.json`: clinic patient records (nested contact details, age,
  diagnosis, blood group, children in the paediatrics ward).

Download them from an engagement's **Personal data → Discovery** tab, or upload them there.
